# Cerebro de CAJA PULSE 360

Mapa de trabajo de la propuesta para CAJATHÓN 2026. El proyecto busca que Riesgos y los asesores puedan detectar qué negocios podrían perder margen antes de caer en atraso y decidir qué vale la pena verificar.
